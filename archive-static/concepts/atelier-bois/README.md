## Prompts
Create a polished wide landscape website UI mockup, straight-on full browser page (not on a laptop), for a fictional French artisan carpentry business named ATELIER BOIS. Premium editorial web design, ivory and warm brown palette, huge serif headline reading 'Le bois, à votre mesure.', small navigation, clear button 'Parlons de votre projet'. Main hero includes a beautiful photorealistic sunlit custom oak kitchen with natural grain and craftsmanship. Below hero small material detail cards. All layout contained within image, refined spacing, highly legible French typography, no customer reviews, no statistics, no logos of real companies. This is an original concept for a web agency portfolio. Landscape 1536x1024.
